\# GRC Posture \& Automation Platform



Automated vulnerability management and asset risk dashboard integrating GLPI, DefectDojo, Trivy, and Nmap Vulners.



\## Features

\- \*\*Asset Collection\*\*: Sync assets from GLPI.

\- \*\*Vulnerability Scanning\*\*: Automated scanning via Trivy \& Nmap Vulners.

\- \*\*GRC Integration\*\*: Push findings directly to DefectDojo.

\- \*\*Posture Dashboard\*\*: Interactive Streamlit dashboard for risk index and asset posture tracking.
